# کرالر متن‌باز Layerly

بررسی محدود و قابل‌بازبینیِ حداکثر پنج صفحهٔ HTML با شواهد JSON؛ بدون API مدل، کلید و وابستگی اجرایی بیرونی. [راهنمای کامل انگلیسی](README.md) · [نسخهٔ تحت وب](https://layerly.net/website-check/)

## اجرا

Python 3.11 تا 3.13:

```bash
git clone https://github.com/farshidghaffari/layerly-site-check.git
cd layerly-site-check
python -m sitecheck demo --out sample.json
python -m sitecheck validate sample.json
```

نمونه کاملاً ساختگی است و شبکه استفاده نمی‌کند. برای سایتی که اختیار بررسی‌اش را دارید:

```bash
python -m sitecheck check https://your-company.example/ --live --out report.json
```

آدرس را عوض کنید. بدون `--live` درخواست شبکه‌ای فرستاده نمی‌شود. گزارش فقط محلی ذخیره می‌شود؛ آن را قبل از اشتراک‌گذاری از نظر URL، متن و اطلاعات تشخیصی بازبینی کنید. فایل خروجی خودکار حذف یا رمزگذاری نمی‌شود.

## معنی خروجی

عنوان، توضیحات، H1، canonical، دستورهای ایندکس، JSON-LD و لینک‌های داخلی در محدودهٔ بودجه بررسی می‌شوند. سقف‌ها: پنج صفحه، ۲۰ تلاش HTTP و ۳۰ DNS. robots و کنترل مقصدهای خصوصی، redirect، TLS و حجم پاسخ در کد و آزمون‌ها قابل‌بررسی‌اند؛ تضمین امنیت کامل نیستند.

`INFO` الزاماً خطا نیست؛ نبود JSON-LD در هر صفحه ایراد قطعی سئو محسوب نمی‌شود. `partial` یعنی بخشی بررسی نشده؛ لینک خارجی عمداً درخواست نمی‌شود. JavaScript، رتبه، ترافیک، بک‌لینک و حضور در پاسخ‌های هوش مصنوعی اندازه‌گیری نمی‌شوند.

سامانهٔ ایمیل، اطلاعات مشتریان و تنظیمات سرور Layerly در این مخزن نیست. مجوز MIT استفاده و تغییر کد را با رعایت متن مجوز اجازه می‌دهد. [گزارش امنیتی](SECURITY.md) و [مشارکت](CONTRIBUTING.md).
