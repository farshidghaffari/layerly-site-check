# کرالر متن‌باز Layerly

بررسی محدود و قابل‌بازبینیِ پنج صفحهٔ HTML در حالت پیش‌فرض و تا ۱۰۰ صفحه با انتخاب کاربر با شواهد JSON؛ بدون API مدل، کلید و وابستگی اجرایی بیرونی. [راهنمای کامل انگلیسی](README.md) · [نسخهٔ تحت وب](https://layerly.net/website-check/)

## اجرا

Python 3.11 تا 3.13:

```bash
git clone https://github.com/farshidghaffari/layerly-site-check.git
cd layerly-site-check
python -m sitecheck demo --out sample.json
python -m sitecheck validate sample.json
```

نمونه کاملاً ساختگی است و شبکه استفاده نمی‌کند. برای سایتی که اختیار بررسی‌اش را دارید:

```bash
python -m sitecheck check https://your-company.example/ --live --out report.json
```

آدرس را عوض کنید. بدون `--live` درخواست شبکه‌ای فرستاده نمی‌شود. گزارش فقط محلی ذخیره می‌شود؛ آن را قبل از اشتراک‌گذاری از نظر URL، متن و اطلاعات تشخیصی بازبینی کنید. فایل خروجی خودکار حذف یا رمزگذاری نمی‌شود.

## بررسی محلی تا ۱۰۰ صفحه

```bash
python -m sitecheck check https://your-company.example/ --live --max-pages 100 --out report.json
python -m sitecheck validate report.json
```

مقدار `--max-pages` بین۱ تا۱۰۰ است. بالاتر از۵، لینک‌های HTML همان میزبان از لایه‌های بعدی هم کشف می‌شوند. در حالت۱۰۰صفحه، سقف۴۰۰ تلاش HTTP و زمان نرم۶۰۰ثانیه است؛ فاصله درخواست‌ها و کنترل‌های robots و مقصد و TLS حفظ می‌شوند. این سقف انتخاب صفحه است، نه تضمین پیدا کردن همه صفحه‌های سایت. JavaScript و کشف URL از sitemap اضافه نشده‌اند.

گزارش بزرگ‌تر نسخه `layerly.check.v0.5-draft` دارد؛ گزارش پیش‌فرض و نمونه‌های قبلی نسخه قبلی را حفظ می‌کنند. فرمان validate هر دو را می‌خواند. `page_limit_reached` یعنی لینک به HTML بیشتری کشف شد که از سقف صفحه بیرون ماند. محدودیت ابزار عمومی سایت با این تغییر افزایش پیدا نمی‌کند.

## بررسی گزارش با مهارت هوش مصنوعی

[مهارت Layerly SEO Basics](skills/layerly-seo-basics/SKILL.md) به دستیار کمک می‌کند گزارش JSON را با شاهد توضیح دهد و مشاهده را با ایراد قطعی اشتباه نگیرد.

اول نمونه آفلاین را بسازید، سپس فایل مهارت و گزارش را به دستیار بدهید. خواندن گزارش به اجرای کد نیاز ندارد؛ خزش واقعی به ابزار اجرا و اختیار بررسی مقصد نیاز دارد. دادن لینک مخزن به‌تنهایی هیچ دسترسی ایجاد نمی‌کند. خود کرالر API مدل مصرف نمی‌کند؛ هزینه و امکانات دستیار انتخابی جداست.

[راهنمای مرحله‌به‌مرحله و متن آماده](docs/AI-REVIEW.md). مهارت خودکار سایت را تغییر نمی‌دهد، گزارشی ارسال نمی‌کند و محدوده خزش را افزایش نمی‌دهد.

## معنی خروجی

عنوان، توضیحات، H1، canonical، دستورهای ایندکس، JSON-LD و لینک‌های داخلی در محدودهٔ بودجه بررسی می‌شوند. سقف‌ها: پنج صفحه، ۲۰ تلاش HTTP و ۳۰ DNS. robots و کنترل مقصدهای خصوصی، redirect، TLS و حجم پاسخ در کد و آزمون‌ها قابل‌بررسی‌اند؛ تضمین امنیت کامل نیستند.

`INFO` الزاماً خطا نیست؛ نبود JSON-LD در هر صفحه ایراد قطعی سئو محسوب نمی‌شود. `partial` یعنی بخشی بررسی نشده؛ لینک خارجی عمداً درخواست نمی‌شود. JavaScript، رتبه، ترافیک، بک‌لینک و حضور در پاسخ‌های هوش مصنوعی اندازه‌گیری نمی‌شوند.

سامانهٔ ایمیل، اطلاعات مشتریان و تنظیمات سرور Layerly در این مخزن نیست. مجوز MIT استفاده و تغییر کد را با رعایت متن مجوز اجازه می‌دهد. [گزارش امنیتی](SECURITY.md) و [مشارکت](CONTRIBUTING.md).
